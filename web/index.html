        marks

        Triage: approve what you want, reject the rest. Turn mark on first (x).

        shiftaltctrl
        dragapprove a rectanglereject itdeselect

        Approved renders get a green outline and nothing painted over them; rejected ones are dimmed so they recede. Esc clears every mark.

        add
        save the current marks as a named set; click a set to load it back, double-click to rename
        clear
        clear the map's marks — saved sets are untouched
        reject rest
        reject every tile that holds a render and is not marked yet: the last step of a pass
        copy
        the current marks as JSON
        mark by search
        approve or reject everything a query matches, whole renders at a time

        Sets live in this browser. A set remembers the zoom it was made at and will not load onto a map that marks at a different granularity.
